# 比赛书架样例

15张封面及书目元数据来自高等教育出版社的公开产品目录。每本书的来源页、图片地址、获取日期和本地SHA-256保存在[manifest.json](manifest.json)。封面仅用于本项目教材识别和交易流程演示，权利归原出版方/权利人所有，不包含书籍正文。

本地图片合计约950KB，随仓库保存。运行演示不访问远程图片服务器，不要求其他设备联网获取封面。更新素材可运行 `apps/api/.venv/Scripts/python.exe infra/fetch-demo-covers.py`（需联网）；普通启动无需此步骤。

出版社书名、作者、版本与ISBN是真实书目；示例售价、品相、笔记、发布账号和交接安排均为虚构数据。页面说明标注“比赛样例，非真实出售”。包含教材、课外读物和免费赠书，可用于完整预约、交接、举报及管理演示。

启动脚本通过 `app.demo_seed` 将首次出现的样例导入数据库，并复制封面到本机图片存储。使用固定UUID避免改名后重复导入；再次启动不重置编辑、预约、成交、管理限制或已删除的图片。历史旧版演示记录保留，不覆盖用户数据。
