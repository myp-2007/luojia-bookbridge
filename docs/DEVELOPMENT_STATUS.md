## 当前限制

- 演示登录是受控的无密码账号选择，学校 SSO 和正式生产认证尚未接入。
- AI任务持久化、异步状态与人工确认已实现。DeepSeek Flash 已通过真实接口和合成封面任务验证。未配置本机凭据时使用模拟模式，真实拍摄的教材照片仍待采样验收。
- PostgreSQL 配置保留，但真实 PostgreSQL 容器、并发和部署恢复验收待有 Docker 环境执行。
- SQLite 演示事务串行化，适用于本地少量数据演示，尚未做大规模负载测试。
- 预约过期采用按需清理，尚未部署定时任务。
- 地图路线、正式公益捐赠审核、课程关联与语义匹配未完成。免费赠书分类复用普通预约流程。
- 浏览器测试使用同一电脑的独立会话，多台物理设备的 Wi-Fi 互通、防火墙与睡眠设置需现场验收。
- API 为兼容旧客户端保留 price（元）与 detail 字段，同时新增 priceCents 和统一错误字段。部分旧列表接口仍返回数组，新接入时需按 OpenAPI 合同处理。

## 2026-11-04 局域网共享迭代

书架、打开的预约面板和个人中心业务列表每5秒自动读取共享数据。后台页暂停轮询，回到页面或连接恢复时尝试同步。请求15秒超时，失败保留上次数据并自动重试。修改与交易操作期间暂停相关视图刷新，避免旧请求覆盖操作结果。

发布表单改为使用仅供本地状态的时间标识，真实书籍ID仍由后端生成，兼容普通HTTP局域网环境。启动脚本列出本机IPv4候选访问地址，VPN/虚拟网卡需由操作者选择实际连接的局域网网卡。未新增数据库迁移、业务API或环境变量。


## 2026-11-07 书架和视觉识别

书架支持组合筛选价格、品相、笔记和可预约状态，并支持价格排序、最新排序和分页。多词查询要求每个词至少匹配书名、作者、出版社或版本之一。默认按书名完整匹配、前缀、包含、其他字段命中排序。同一排序值按发布时间和ID稳定排序。百分号与下划线按字面量匹配。

DeepSeek Flash 已用一张合成书籍封面验证官方视觉API和应用任务接口，正确读取书名和出版社。已有本机配置启用该服务，仓库示例使用占位符。未新增数据库迁移或依赖。
