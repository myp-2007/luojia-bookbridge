# 本机网站使用与数据恢复

当前入口是普通注册和密码登录，不再使用固定演示账号选择。学校认证暂缓，院系为用户自行填写，不代表学校核验。

## 启动

1. 双击项目根目录start.cmd，或在PowerShell运行 `./infra/start-local.ps1`。
2. 等待窗口显示Uvicorn running，打开 http://localhost:8000 。
3. 点击“我的”或“发布”，按提示注册自己的账号。账号为3至32位英文字母、数字、下划线、点或短横线，大小写视为同一账号；密码8至128字符，昵称可以用中文。
4. 第一个在主机localhost注册、且系统尚无真实管理员的账号成为本机管理员。手机等远程注册始终普通用户，不需要默认管理员密码。
5. 网站运行时保持窗口开启；Ctrl+C停止。已有新版服务运行时，启动脚本显示现有地址；升级旧版时先停止旧窗口，避免两个版本抢占端口。

首次缺少工程依赖会自动安装，需要Python 3.12+、Node.js和npm。可用 `-Setup` 重装依赖，`-Port 8080` 指定端口。旧start-demo.ps1兼容转发到当前启动方式，语义已改为真实账户网站。

## 常用流程

- 搜索：主页输入完整书名、作者、出版社、版本或ISBN，点击“搜索”或回车；也可输入高数/线代/大物/概统。发现页进一步筛价格、品相、笔记、排序及分页。查询保存在网址里，刷新和返回保留条件。
- 发布：登录后进入发布页，填写书名、价格和交接地点，添加最多3张真实照片，每张不超过5MB。免费赠书自动零元。保存后进入详情，其他人的书架5秒内同步。
- 个人资料：我的 → 编辑个人资料，可上传2MB以内头像、修改昵称、性别、院系、简介和联系方式。性别与联系方式不放进公开书友资料；联系方式仅在卖家接受预约后展示给交易对方。
- 管理书籍：我的发布 → 编辑资料/管理图片/下架。预约中、已完成或受管理限制的书籍不可更改资料。
- 交易：买家在详情点击预约交接，填写地点与可选建议时间，再确认预约。卖家在记录 → 我卖出的接受。线下核对书籍后双方各自确认完成。一方确认后需通过争议处理，不能直接取消。
- 收藏：书架爱心或详情收藏按钮，保存到我的收藏；不同账号相互独立。
- 修改密码：账户设置 → 修改密码。完成后所有设备会话退出，用新密码重新登录。当前没有邮箱/短信找回，请记住账号和密码。
- 管理员：个人中心进入书籍与操作管理、举报与争议处理。限制书籍必须填写说明，解除后由发布者重新上架。

旧版没有密码的样例账号不再能够登录，相关旧书籍保留浏览但不可接收新预约，避免出现无人能接受的交易。可用管理员下架旧记录；新注册账号发布的书籍正常参与完整交易。不会把旧样例自动算成新用户的发布数量。

## 多人使用

每人使用自己的设备或独立浏览器配置，连接与主机可互访的局域网。在手机打开 `http://主机局域网IP:8000`，不要输入手机自己的localhost。启动脚本会列出网卡IP，VPN/虚拟网卡地址未必适用。若手机打不开，检查是否同网、校园网络是否隔离设备和Windows防火墙。实际手机Wi-Fi互通仍需现场验收。

## 本机数据与备份

数据库沿用 `apps/api/demo_bookbridge.db`；书籍照片和头像在 `apps/api/storage/demo-uploads`。历史路径保留是为了兼容已有数据，所有正常注册、资料修改和书籍写入都真实持久化。每次启动前备份为 `apps/api/backups/时间戳/demo.db` 和 `uploads.zip`。不会覆盖注册数据或重置交易。

恢复时先停止服务，将当前数据库和图片另存留档；选择同一批次备份，把demo.db复制回数据库路径，uploads.zip解压回图片目录，再启动网站。较早备份会失去其后修改，确认批次后再恢复。不要把数据库、图片或.env传到GitHub。

## 智能找书与百度地图

登录后从首页打开「智能找书」，输入书名、版本、作者或 ISBN，再选择价格最低或距离最近。DeepSeek 把自然语言转换成检索词，书架按实际价格和地点数据排列结果。模型不可用时按原输入检索，可改用简短书名或 ISBN。

- 距离排序需要搜索并选用一个公共地点作为起点，结果显示近似直线距离。还未标记地点的匹配书籍仍可按价格查找。
- 发布、编辑和预约时可在地点输入框填入校门或建筑名，再点击「在百度地图搜索」选用地点。发布或编辑时选用的地点可参与距离排序。详情和交易记录可打开百度地图查看。
- 在 `apps/api/.env` 配置百度地图 Web 服务类型的 `BAIDU_MAP_AK`，按百度控制台要求设置服务端出口 IP 白名单，重启服务后启用地点检索。无 AK 时仍可手填地点。

## DeepSeek 与拍照识书

在 `apps/api/.env` 中配置以下项后重启。真实识别与智能找书由服务端调用，Key 只保存在本机。未配置时可以手动录入书籍资料和按原关键词找书。

```dotenv
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_API_KEY=
BAIDU_MAP_AK=
```

DeepSeek 智能找书调用官方 Flash 模型。拍照识书继续使用 `AI_MODEL` 指定的模型。旧版本配置中的视觉模型别名由 DeepSeek 兼容。

在自己可编辑书籍的详情或发布管理中进入AI识别，先上传清晰封面；核对候选、勾选确认后保存。失败保留手动编辑，不自动覆盖资料。首次真实高数封面调用已在前一轮验证；真实手机照片的识别质量仍需采样，不能把Mock回归测试当准确率。
