## 本轮结果

- 后端：`./.venv/Scripts/python.exe -m pytest -q`，49项通过。保留一条现有Starlette/httpx弃用提示。
- 前端：`npm.cmd run build`和`npm.cmd run lint`通过。
- 浏览器：`npm.cmd run test:e2e`，14项通过，Edge无头浏览器，390px手机与1440px桌面布局；真实HTTP API和独立SQLite测试库。
- PostgreSQL：完整Alembic离线升级SQL生成通过，包含新增账户资料、收藏和限流表；未连接真实PostgreSQL实例。
- 本机升级：启动前备份，原5个历史身份和19本书保留；旧无密码身份在正常模式不可登录、不可接收新预约。新用户发布的书籍正常交易。
- 自动测试使用临时图片目录和测试库，AI使用显式Mock，不消耗真实模型额度、不污染用户资料。

## 手动使用流程

1. 双击根目录`start.cmd`，保持服务窗口开启；浏览器打开`http://localhost:8000`。
2. 点击我的→立即注册，自己设置账号和密码。尚无真实管理员时，首次从本机localhost注册的账号成为管理员；远程注册始终是普通用户。
3. 发布一本自己的书，上传封面；使用另一个浏览器配置或另一设备注册第二个账号。
4. 第二个账号搜索该书、预约，发布者在记录中接受，双方分别确认交接；检查个人书架、统计和记录。
5. 修改头像与资料，退出并重新登录；停止、重启服务后检查数据保留。

## 尚需现场验证

多台实体手机的Wi-Fi互通、校园网络隔离和Windows防火墙需要在实际网络验证。自动化五会话测试验证数据共享，不能证明手机网络可达。主机需保持开机和唤醒。

本轮未重新调用付费模型。此前真实高数封面识别成功记录见开发进度；手机拍摄的识别质量仍需真实样本。没有学校认证、邮件/短信找回密码、在线支付、站内聊天或地图导航入口。不要将测试结果理解为互联网公开部署或大规模负载验收。
