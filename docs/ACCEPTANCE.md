# 本机多人功能验收

当前目标：一台电脑运行动态站点，约五位参与者用独立浏览器或手机账号共享同一个数据库。学校认证暂不接入，演示账号由启动脚本初始化。

| 入口 | 可完成的操作 | 自动化覆盖 |
| --- | --- | --- |
| 我的/登录 | 选择账号、刷新保持登录、退出、昵称和主动分享联系方式 | API会话/权限与浏览器资料测试 |
| 首页/发现/分类 | 搜索、组合筛选、排序、分页、免费赠书和课外读物 | 真实API浏览器测试 |
| 书籍卡片 | 详情、浏览相册、选择图片、预约、反馈、发布者AI识别 | 浏览器图片/交易/反馈测试 |
| 发布 | 填写资料、上传图片、保存到共享书架 | 双浏览器发布和自动同步测试 |
| 我的发布 | 编辑、上下架、管理最多3张图片、删除、设封面、AI候选核对 | 浏览器图片/编辑/AI测试 |
| 我的预约与交接 | 买入/卖出、接受、拒绝、取消、联系方式、双方确认、争议 | API状态机/并发与双浏览器测试 |
| 免费赠书 | 零元发布、预约、双方确认完成赠送 | 独立会话赠书浏览器测试 |
| 我的反馈/处理举报 | 提交书籍问题、查看结果、管理员核实或驳回、处理交易争议 | API与浏览器测试 |
| 管理书架 | 搜索所有状态、限制展示、解除限制、分页审计记录 | 管理员/发布者双会话测试 |
| 网络/重启 | 5秒同步、隐藏暂停、失败保留数据、恢复重试、持久化、启动前备份 | 多会话/故障注入与SQLite备份恢复测试 |

常规交易：小珞发布 → 小桥预约 → 小珞接受 → 联系对方约定地点 → 现场核对书籍 → 双方分别确认 → 双方显示已完成。免费赠书使用同一流程，后端强制售价为0。

管理员演示：普通账号反馈书籍问题 → 演示管理员在“处理举报”核实 → 在“管理书架”填写说明并限制书籍 → 书架隐藏、发布者看到原因 → 管理员解除 → 发布者确认后重新上架。已有交易保留；受限交易取消后不会自动恢复在售。管理说明不可填写私密联系方式。

AI演示：在“我的发布”选择带封面的书 → AI识别 → 等待候选 → 对照封面核对 → 勾选确认 → 保存。没有图片、网络或模型服务异常时显示明确原因，仍可手动编辑。自动化测试隔离为mock，不消耗真实额度。真实服务验收结果另记开发进度，不能把模拟测试当作识图准确率。

物理设备验收仍需现场完成：主机与手机同一可互访Wi-Fi，允许系统防火墙的对应端口，主机保持唤醒；五人分别发布、预约、等待自动同步；关闭并重新运行启动脚本，确认数据保留。自动浏览器会话验证业务共享，不替代实际Wi-Fi检查。


2026-11-08本机验收记录：后端39项测试通过，浏览器14项流程全部通过（Edge无头浏览器，独立真实API与SQLite测试库），前端build/lint通过。DeepSeek真实调用仅用高数上册封面完成一次任务，成功返回四个书目字段，没有自动写入书籍表。实际本机升级前后比对保留全部旧书籍和用户记录；启动前自动备份。PostgreSQL只生成并检查离线迁移SQL，未进行容器验收。
