# 本机演示与恢复指南

## 启动与账号

仓库根目录执行 `./infra/start-demo.ps1 -Setup` 安装工程依赖并启动，后续使用 `./infra/start-demo.ps1`。可用 `-Port 8080` 修改本机端口。脚本构建网页，使用独立 SQLite 演示库，执行迁移和演示数据初始化，再启动 API。开发环境允许从固定演示账号中选择登录。

| 账号 | 昵称 | 演示用途 |
| --- | --- | --- |
| demo-seller | 小珞 | 初始书籍发布者，接受预约 |
| demo-buyer | 小桥 | 搜索、预约、收书 |
| demo-reader | 小书 | 第三位参与者、权限验收 |
| demo-fourth | 小林 | 第四位参与者、竞争预约 |
| demo-admin | 演示管理员 | 核实并处理举报和争议 |

点击“我的”选择账号。每个浏览器会话当前只对应一个用户，使用不同设备、不同浏览器或不同浏览器配置模拟多人。同一浏览器的普通标签页共享登录 Cookie。

演示登录无密码，仅在 development/test 且 ALLOW_DEV_AUTH=true 时开放，适用于虚构数据的受控比赛演示。正式学校登录和外网部署应另行接入认证。默认 ALLOW_LEGACY_HEADERS=false，请求头无法伪造身份或管理员角色。兼容开关仅供旧接口回归测试。

## 五分钟演示流程

1. 小珞登录，点“发布”，输入书名、作者、版本、价格、笔记和交接地点，上传真实封面。
2. 小桥在另一会话登录，搜索同一本书，打开详情，提交预约。
3. 小珞进入“记录”，切换“我卖出的”，接受预约。
4. 双方打开“查看对方联系方式”，只有主动提供的联系内容会展示。联系方式在“我的 → 昵称与联系方式”编辑。
5. 线下核对书籍和付款后，小桥确认收书，小珞确认交书，交易完成。
6. 展示“我的发布”中的编辑、下架和重新发布。预约中或完成的书籍无法修改。
7. 如演示争议，另建一笔预约，在接受后申请争议处理。管理员进入“我的 → 处理举报”，核实说明并选择取消或完成交易。

## 数据保存和备份

演示库为 `apps/api/demo_bookbridge.db`，图片在 `apps/api/storage/demo-uploads`。初始化脚本只补充缺失的演示记录，不清空已有交易。待接受预约24小时后，在下次列表查询或预约时清理。接受后的交接预约不会自动过期。

每次启动前，脚本为已有演示库创建一致性 SQLite 备份和图片 ZIP，目录为 `apps/api/backups/时间戳`。演示中使用虚构的个人信息，备份不进入 Git。

恢复时先停止服务，将当前库和图片另存留档。把选定备份的 `demo.db` 复制为 `apps/api/demo_bookbridge.db`，将 `uploads.zip` 解压到 `apps/api/storage/demo-uploads`，再执行启动脚本。数据库和图片应使用同一备份批次。恢复到较早备份可能丢失之后的交易记录，请先核对时间。数据库恢复查询已通过自动测试，人工图片归档恢复需实际演练。

## 多设备访问

先确认本机 <http://localhost:8000> 正常，再在另一设备打开 `http://电脑的局域网IP:8000`。设备需能互相访问，现场电脑保持开机，避免睡眠。校园访客 Wi-Fi 可能隔离客户端，可以提前准备可互访的局域网。当前尚未在多台物理设备上完成现场网络验收。

所有网页请求使用相对 `/api/v1` 和 `/storage`，手机会请求主机地址。开发模式使用 Vite 代理，完整本机演示由 FastAPI 直接提供构建网页。

## PostgreSQL 路径

`docker compose -f infra/docker-compose.yml up --build` 启动 PostgreSQL 和演示 API，前端可由 Vite 启动并代理到8000。Compose 当前明确配置为开发演示环境，会初始化虚构账号。数据库监听仅映射到127.0.0.1。当前环境没有 Docker，因此 PostgreSQL 容器和真实 PostgreSQL 并发测试仍待执行。

## 外部资源

真实 AI 图片识别需要确认服务商、模型、接口和 API Key，并准备图片样例验收。学校 SSO 需要学校提供接入信息。地图和正式公益捐赠流程需确认交接点与接收方规则。上述功能的现状见开发交接文档。


## AI服务接入

新克隆的项目默认 `AI_PROVIDER=mock`，模拟候选会明确标注回显资料。任务保存在ai_tasks，状态为queued/running/succeeded/failed，运行中任务会复用，90秒未完成的任务在查询时标记失败，允许手动重试。服务运行在FastAPI后台任务中，适用于小规模演示，进程停止后由超时恢复处理。

已有兼容 `/chat/completions` 的视觉模型适配器。服务须支持图片data URL与JSON对象输出。设置 `AI_PROVIDER=openai-compatible`、`AI_BASE_URL`（包含版本前缀，如服务商提供的/v1）、`AI_MODEL` 和 `AI_API_KEY` 后重启。示例字段在apps/api/.env.example中，Key只保存在本机环境或被忽略的.env文件。启动脚本不覆盖这些AI配置。

发布时先上传封面，再打开自己书籍的“查看AI候选信息”。识别成功后人工对照实物，勾选确认再保存。模拟结果会标注为模拟，真实模型返回的置信度同样需要人工核对。结构化不合法、服务失败或超时会展示错误，并保留手动编辑入口。已用合成教材封面完成 DeepSeek Flash 的官方接口和项目异步识别任务验证，真实拍摄的教材照片准确率仍需采样评估。

DeepSeek 配置保存在本机 `apps/api/.env`。该文件被 Git 忽略，请在其中设置下列字段并重启后端。Key 原文只保留在该本机文件。

```dotenv
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_API_KEY=<本机填写>
```

模型命名和图片格式见 [DeepSeek 官方视觉指南](https://api-docs.deepseek.com/guides/vision/)。



## 自动共享与连接提示

网页、打开的预约记录和个人中心列表每5秒同步一次。A在自己的会话发布、预约或确认，B已经打开的对应页面会在下一次同步显示变化。后台页面暂停轮询，切回时重新读取。手动“刷新书架/刷新记录”仍可使用。

请求超过15秒会提示超时，临时失败保留上次成功读取的内容，随后继续尝试。只要设备能访问主机局域网地址，即使局域网没有互联网也会继续请求本机服务。服务重启后使用原数据文件，页面恢复连接即可重新同步。AI外部模型调用仍需要相应外部网络与配置。

启动时会列出本机IPv4访问地址候选。选择与参与者设备同一网络的Wi-Fi/有线网卡地址，VPN和虚拟网卡地址可能无法从手机访问。首次现场验收仍须用另一台真实设备打开该地址。


## 书籍样例、相册和管理员

2026-11-08起，启动会导入15本带本地封面的教材/读物/赠书样例，旧数据保留。样例来源和说明见`seed/demo-books/README.md`。演示价格和品相均为虚构，不是真实售书。重复启动不会重置修改或交易。

在“我的 → 我的发布”打开“管理图片”，可补传、设封面和删除；详情页点击缩略图切换图片。AI识别同样可从我的发布进入，须先上传清晰封面，候选核对后才保存。交易中或管理限制中的书籍暂停资料和图片编辑。

登录“演示管理员”，在“我的 → 管理书架”搜索并限制/解除书籍；“操作记录”查看审计。限制期间禁止新预约，已有交易保留。解除后由发布者重新上架。免费赠书价格固定0，预约和交接流程与教材一致。

完整按钮验收、多人交易与现场检查见[功能验收清单](ACCEPTANCE.md)。学校认证暂不接入，比赛仍使用当前演示账号。
